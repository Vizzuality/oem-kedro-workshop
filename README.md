# Geospatial data pipelines with Kedro

Slides: [vizzuality.github.io/oem-kedro-workshop](https://vizzuality.github.io/oem-kedro-workshop/)

## Setup

The workshop includes a hands-on session that requires a recent Python installation and a package manager.
I recommend using [`uv`](https://docs.astral.sh/uv/) to simplify setup.

To install `uv`, follow the [official installation guide](https://docs.astral.sh/uv/getting-started/installation/).
